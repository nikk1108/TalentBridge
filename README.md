# TalentBridge — AI-Powered Hiring Platform

A full-stack recruitment and applicant tracking platform designed to connect candidates and recruiters through streamlined hiring workflows and AI-assisted recruitment tools.

**Live Demo:** https://project-ejfwm.vercel.app/login  
**Repository:** https://github.com/nikk1108/TalentBridge

## Overview

TalentBridge brings job discovery, candidate applications, recruitment management, and AI-assisted evaluation into one platform. Candidates can explore opportunities and track applications, while recruiters can manage job postings and hiring pipelines.

## Key Features

- **Role-Based Authentication** — Separate candidate and recruiter experiences.
- **Job Management** — Create, browse, and manage job listings.
- **Application Tracking** — Submit applications and monitor their status.
- **Recruiter Dashboard** — Manage candidates and recruitment workflows.
- **Candidate Dashboard** — Track applications and hiring progress.
- **AI-Assisted Recruitment** — Resume parsing, job-description assistance, candidate matching, and interview-question generation.
- **Interview Management** — Organize interview-related information and recruitment stages.
- **Cloud-Based Deployment** — Deployed web application with a full-stack architecture.

## Tech Stack

- **Frontend:** React, JavaScript, Vite, Redux Toolkit
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT
- **Additional Technologies:** REST APIs, AI integrations, Cloudinary

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/nikk1108/TalentBridge.git
   cd TalentBridge
   ```

2. Install dependencies in the frontend and backend directories.
3. Configure environment variables for MongoDB, authentication secrets, file uploads, and any required AI services.
4. Run the frontend and backend using the scripts defined in their respective `package.json` files.

Refer to the repository configuration for the exact commands and required environment variables.

## Engineering Focus

TalentBridge explores full-stack application architecture, role-based access control, API design, database modeling, recruitment workflows, and AI integration in a practical product.
